# Suggested Code Availability statement

After the GitHub repository is public, the manuscript can use wording such as:

> Analysis code supporting the principal computational analyses reported in this study is publicly available at GitHub: [REPOSITORY URL]. The repository documents the public data sources, analysis settings and module-specific input requirements. Source datasets are available from the original public resources and are not redistributed with the code.

After archiving a tagged GitHub release in Zenodo, use:

> Analysis code supporting the principal computational analyses reported in this study is publicly available at GitHub: [REPOSITORY URL] and archived on Zenodo: [DOI]. Source datasets are available from the original public resources and are not redistributed with the code.
