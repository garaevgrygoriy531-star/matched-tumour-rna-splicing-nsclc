# Data directory

`analysis_gene_set.csv` contains the clinically anchored 68-gene analysis set used in the study.

Participant-level and sample-level data are not distributed in this repository. The study uses public data from TCGA/GDC, MC3, recount3/Snaptron, GTEx and CPTAC/LinkedOmicsKB. Retrieve source data from the original providers and follow their access and use conditions.

The repository `.gitignore` excludes raw, derived and private data directories as well as analysis outputs.
